`osm.json.gz` contains a public OSM extract obtained through Overpass. OSM data is
made available under the Open Data Commons Open Database License 1.0 (ODbL-1.0).
Derived road-network snapshots and data summaries retain this data attribution
and license; the code's license does not replace the source data license.

- Attribution and license information: https://www.openstreetmap.org/copyright
- License text: https://opendatacommons.org/licenses/odbl/1-0/
- Source, query, raw-content hash and timestamps: `source.json`
- Processing rules and limitations: `../../../docs/OSM_PIPELINE.md`

This snapshot is a reproducible demonstration baseline, not independently
verified ground truth and not a statement about current real-world roads.
