# 完整在线服务：上传、分析、核验与持久化

## 当前交付范围

完整服务功能已接入现有 Streamlit 五页工作台。GitHub Pages 继续提供公开只读演示；Python 服务需要额外托管环境，不能把 Pages 链接当作完整后端地址。

公开访客可浏览固定演示；编辑访问码解锁可信编辑者共用的工作区。上传数据、历史任务和核验记录不会自动发布到 Pages，也不会发送给未解锁的访客。当前不是注册用户平台，没有个人账号、自助找回密码或不同编辑者之间的私有空间。

## 使用流程

1. 打开完整服务，在右上角“编辑登录”输入管理员配置的访问码。
2. 进入 Data Management，下载完整示例数据包，或按下文准备自己的数据。
3. 上传 ZIP，检查网络版本与五张表的记录数，再点击“运行检测与假设回放”。
4. 系统在独立进程中调用原有检测和回放算法，最长运行 5 分钟。成功后切换到该批次结果；失败保留输入与日志，不覆盖当前结果。
5. 在地图和详情页检查证据、切换回放，填写人工核验记录。
6. 在任务列表选择历史结果，或返回公开演示数据。退出编辑后恢复公开演示，不向访客展示上传记录。

旧版 CSV/XLSX 校验、DuckDB 批次保存与 Excel 日报入口继续保留；旧版问题记录不能冒充有时序和方向信息的 V2 轨迹。

## V2 输入数据包

ZIP 最大 15 MB，解压总大小不超过 60 MB。根目录必须恰好包含：

```text
dataset.json
road_segment.csv
road_node.csv
turn_restriction.csv
trajectory_point.csv
user_feedback.csv
```

不接受子目录、路径穿越、加密文件、符号链接、注入答案或额外文件。CSV 为 UTF-8；字段定义见 `src/analysis_inputs.py`，可以从 `data/demo/upload-example.zip` 修改。布尔值明确填写 `true` 或 `false`。轨迹须包含 ID、点序号、带时区时间、坐标、速度、方向等信息；反馈没有记录时保留表头即可。

`dataset.json` 示例：

```json
{
  "label": "my-xuhui-sample",
  "network_version": "my-network-v1",
  "synthetic": {
    "road_segment": false,
    "road_node": false,
    "turn_restriction": false,
    "trajectory_point": false,
    "user_feedback": false
  }
}
```

五张表必须使用相同网络版本，合成标记必须与描述一致。来源是否真实属于上传者声明，不是系统认证。路段最多 2500、节点 3000、转向限制 1000、轨迹点 150000、反馈 2000。当前规则和地图文案限定上海小范围样本，边界单边跨度不超过 0.06 度，不支持任意城市直接套用。

网络拓扑或模式错误会阻止运行；观测异常沿用原有清洗逻辑，拒绝行及原因保存在任务结果中。上传包不包含独立答案，因此新批次的 Precision / Recall 保持未计算，不继承演示数据的指标。

## 持久化与运行限制

所有完整服务数据位于 `ROADINSIGHT_DATA_DIR`：

```text
workspace.sqlite      任务状态、数据版本与结果绑定
jobs/<任务 ID>/       原始包、规范化输入、分析、回放、页面快照、日志
reviews/              按分析版本独立保存的追加式核验记录
uploads.duckdb        旧版上传批次
```

编辑访问码只从环境变量读取，不写入以上目录、不下发到页面，不传给分析子进程。服务器检查每项写入和私有任务读取权限；隐藏按钮不是权限控制手段。

每个持久卷仅运行一个服务进程，文件锁阻止第二个实例；分析与写入串行，重复请求不重复生成任务。当前工作区限制 50 个分析任务，磁盘空闲不足 500 MB 时拒绝新任务；需要管理员备份归档或扩容。服务重启时未完成任务标记为“已中断”，不会误标为成功，也不会自动重跑。

## 部署

需要支持 Python 或 Docker、HTTPS 和持久卷的环境。建议先用至少 2 GB 内存的小规格实例验证实际样本；这是演示规模服务，不是高并发平台。新增托管账号、费用与域名配置由项目所有者选择。

配置平台的私密环境变量：

| 名称 | 设置 |
| --- | --- |
| `ROADINSIGHT_DATA_DIR` | 平台持久卷中的绝对目录，如 `/var/data/roadinsight` |
| `ROADINSIGHT_EDITOR_TOKEN` | 私密的随机编辑访问码，至少 32 字符；不要写入 GitHub |
| `PORT` | 平台要求的监听端口，默认 8501 |

启动命令：`python scripts/13_serve.py`。启动器强制在线模式，缺少持久化目录配置或访问码时拒绝启动；保留跨站请求保护。健康检查为 `/_stcore/health`。平台应提供 HTTPS；不要把带编辑功能的服务以明文 HTTP 直接开放公网。

Docker 镜像以非 root 用户运行，示例本地部署：

```sh
docker build -t roadinsight-v2 .
docker run --name roadinsight -p 127.0.0.1:8501:8501 --env-file .env --mount type=volume,source=roadinsight-data,target=/var/data/roadinsight roadinsight-v2
```

`.env` 由 `.env.example` 复制并在本机填写，已加入忽略列表。命名卷在容器替换后保留；如改用绑定目录，须赋予容器用户 UID 10001 写权限。不要把真实上传目录或密钥复制进镜像。平台持久卷、备份和费用未配置时，不应宣称完整服务已上线。

例如 Render 官方文档说明：默认文件系统会随重启或部署丢失，持久磁盘需使用支持它的付费服务；详见[持久磁盘说明](https://render.com/docs/disks)。本文不自动创建付费资源。

## 备份与恢复

先停止服务，避免与另一实例竞争同一数据目录，再在可信管理员环境执行：

```sh
python scripts/12_backup_workspace.py --data-dir /var/data/roadinsight --output /backups/roadinsight-backup.zip
```

备份使用 SQLite 的一致性备份接口，包含任务、源数据、快照、核验和旧批次，不包含编辑访问码；输出必须位于工作区外且不能覆盖已有文件。备份包含上传内容，应存放在私有位置。

恢复时，将可信备份解压到一个新的持久化目录，配置相同的数据目录变量并重新启动；保留旧目录直到核对任务、快照和核验记录。当前有手动一致性备份工具，尚未接入云平台自动备份计划。

## 验收

自动测试覆盖真实示例包分析、ZIP 边界、来源标记不一致、超时保留、重复提交、持久化恢复与备份恢复。浏览器脚本 `scripts/11_verify_server.cjs` 会写测试数据，只允许指向本机隔离测试服务，不能直接对生产运行。

CI 构建实际 Docker 镜像，在隔离持久卷中运行访客拒绝写入、编辑解锁、上传分析、核验保存、旧版日报和退出隔离检查，再重启容器检查任务是否保留。通过后才更新只读 Pages 站点；这个 CI 测试容器不是公开托管服务。
