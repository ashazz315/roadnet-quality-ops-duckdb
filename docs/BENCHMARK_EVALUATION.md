## 2. 匹配与计数口径

规则固定在 [`config/evaluation.json`](../config/evaluation.json)，评估算法 `fault-object-matching-v1`；报告记录规则和源码 SHA-256。

| 类型 | 必须满足的匹配条件 |
| --- | --- |
| 连接断裂 | 类型为连接、对象为节点；证据中的两个节点精确对应答案中的新增端点和原端点，忽略节点对顺序 |
| 单行冲突 | 类型为单行、对象为路段；当前路段 ID 与答案映射一致，证据中的当前方向与故障后方向一致 |
| 禁转冲突 | 类型为转向、对象为 turn；via 节点和有向入口边一致；`no_*` 要求有向出口边也一致；移除 `only_*` 时允许匹配该约束原本禁止、当前允许的其他出口 |
| 缺路候选 | 类型与对象类型一致；EPSG:32651 米制投影，20 m 缓冲；候选在故障走廊内的长度比例 ≥80%，故障在候选走廊内的长度比例 ≥50% |

类型错误或对象错误不能仅凭位置接近获得 TP。缺路规则要求双向覆盖，避免一个很短的交叉片段或很长的偏离走廊被计为发现整段道路；平行道路仍可能在缓冲内混淆，因此必须披露阈值与范围。

匹配图采用按 ID 排序的增广路径算法，求**最大匹配数量**，结果与输入行顺序无关；不根据置信度筛选、修改候选，也不把同一故障重复计入 TP。多个候选竞争同一故障时，未匹配候选计为 FP，并保留“重复／竞争告警”原因。

- TP：匹配成功的候选—故障对数。
- FP：未匹配的候选数，只是“相对已注入故障”的闭集评估记号，不证明该位置现实中正常。
- FN：没有候选匹配的注入故障数。
- Precision=`TP/(TP+FP)`；Recall=`TP/(TP+FN)`；F1=`2TP/(2TP+FP+FN)`。相应分母为零时保存 `null`。
- 没有有限且独立标注的负例全集，**TN、FPR 均为 `null`**。候选级 FP 与故障级 FN 不拼成虚构的完整二分类混淆矩阵。

## 3. 一键完整复现

安装现有 Python 依赖后，在仓库根目录运行，无需下载新的地图：

```sh
python scripts/09_validate.py --output data/runtime/validation_demo
```

流程：重建固定 Golden → seed 42 故障与输入 → 检测 → 假设回放 → 独立评估；随后以相同参数再次生成 Benchmark 并运行检测、回放和评估。每个阶段使用独立进程，保存日志，失败保留 `failure.json`，没有静默重试。拒绝覆盖已存在的输出目录。

`suite.json` 检查全部 Benchmark 产物字节、排除运行时间和 UUID 后的分析／回放内容指纹、逐对象匹配与指标以及评估规则一致。GitHub CI 同样执行此命令，并上传报告和日志。

不同系统或依赖版本的浮点与 Parquet 字节可能不同，跨平台不要求匹配提交的 Windows 字节；每个平台都要在本环境两次重跑一致。提交的 [`default_suite.json`](../data/validation/default_suite.json) 保留本次 Windows 重跑记录。

只评估已有结果：

```sh
python scripts/09_evaluate.py --benchmark data/runtime/benchmark_seed42/manifest.json --analysis data/runtime/analysis_seed42/manifest.json --replay data/runtime/replay_seed42/manifest.json --output data/runtime/evaluation.json
```

可追加 `--suite <suite.json>` 绑定重复性证据。只有输入指纹、全部分析／回放结果指纹、评估源码、规则和逐对象指标一致，才能显示重复性通过；否则拒绝附加。没有重复报告时明确显示 `not_run`。

## 4. 数据质量

当前输入接收 60004 / 60004 个轨迹点；必填空值、重复点键、非法坐标、时间异常、异常速度均为 0。这是受控生成数据的校验结果，不表示没有 GPS 噪声或地图匹配问题。

匹配规则接受率 87.5458%；平均候选距离 1.9139 m，P95 为 4.7218 m。距离基于已接受的匹配点，不是有真值支持的定位误差。低评分候选 3 / 18（低于 0.70）；评分仍未校准。

每项异常率按原输入点数作分母；拒绝原因允许重叠，同一行不重复计入拒绝总数。匹配接受率低于配置值 0.70 时，验证中心显示数据质量告警；该阈值不是准确率承诺。
